문제-33

성공은 단순한 욕망의 문제가 아니라, 인내를 필요로 한다.

문제

다음 글에서 필자가 주장하는 바로 가장 적절한 것은?

Too many times people, especially in today’s generation, expect things to just happen overnight.

When we have these false expectations, it tends to discourage us from continuing to move forward.

Because this is a high tech society, everything we want has to be within the parameters of our comfort and convenience.

If it doesn’t happen fast enough, we’re tempted to lose interest.

So many people don’t want to take the time it requires to be successful.

Success is not a matter of mere desire; you should develop patience in order to achieve it.

Have you fallen prey to impatience? Great things take time to build.

* parameter 매개 변수, 제한
정답 ① 성공하기 위해서는 인내심을 길러야 한다.
핵심 문법·구문 중요 어휘·표현 구조·섹션 핵심 주장

문장 구조S peopleV expect

통문장 사람들은 일이 하룻밤 사이에 일어나기를 너무나 자주 기대한다.

어휘overnight 하룻밤 사이에, 아주 짧은 시간에 동의어 instantly / rapidly / in no time 반의어 gradually / slowly

통문장 우리가 이러한 잘못된 기대를 가지면, 그것은 우리가 계속 앞으로 나아가는 것을 단념하게 만드는 경향이 있다.
문법discourage A from v-ing · A가 ~하는 것을 단념하게 하다   tend to-v · ~하는 경향이 있다
어휘move forward 앞으로 나아가다, 진전하다 동의어 proceed / go on / make progress 반의어 stop / remain stuck
배경 설명

문장 구조S thisV isS everything we wantV has to be

끊어 읽기 오늘날은 첨단 기술 사회이기 때문에 / 우리가 원하는 모든 것은 / ~ 안에 있어야 한다 / 우리의 안락함과 편리함이라는 제한 범위 안에

통문장 오늘날은 첨단 기술 사회이기 때문에, 우리가 원하는 모든 것은 우리의 안락함과 편리함이라는 제한 범위 안에 있어야 한다.

통문장 그 일이 충분히 빨리 일어나지 않으면, 우리는 흥미를 잃고 싶은 유혹을 받는다.
문법be tempted to-v · ~하고 싶은 유혹을 받다   fast enough · 충분히 빨리

02

문법 확장

지문에 나온 표현과 연결되는 대표 유형만 정리

① 목적어 + to부정사

expect / want / allow / encourage / advise / force / enable / persuade + O + to-v

② A + from + v-ing

discourage / prevent / stop / keep / prohibit / deter / dissuade A from v-ing

③ 목적의 to부정사

to-v / in order to-v / so as to-v · ~하기 위해
in order not to-v / so as not to-v · ~하지 않기 위해

④ enough

형용사·부사 + enough / enough + 명사 / adj·adv + enough to-v

⑤ 경향·가능성

tend to-v / be likely to-v / be apt·prone to-v

⑥ 목적격 관계대명사 생략

(that) we want / (that) it requires처럼 목적격 관계대명사는 생략 가능

04

글의 전개도

01문제 제기

성공이나 성취가 하룻밤 사이에 이루어지기를 기대함.

02원인·배경

빠르고 편리한 결과를 기대하는 현대 사회의 모습.

03문제 심화

결과가 늦어지면 흥미를 잃고 계속 나아가기를 포기함.

04핵심 주장

성공에는 시간이 필요하므로 인내심을 길러야 함.

05결론·재강조

위대한 일은 시간이 걸리므로 조급함을 피해야 함.

05

필자의 주장

성공은 단순히 바라는 것만으로 이루어지지 않으며, 시간이 걸리는 과정을 견디기 위해 인내심을 길러야 한다.
06

선택지 분석

① 정답 성공하기 위해서는 인내심을 길러야 한다. → 글의 핵심 주장과 일치함.

② 안락함과 편리함은 배경 설명일 뿐, 한계에 도전해야 한다는 주장은 없음.

③ 빠르게 대응해야 한다는 것이 아니라 빠른 결과를 기대하는 태도를 비판함.

④ 능동적 행동보다 성공에 필요한 인내심을 강조함.

⑤ 좋아하는 일을 해야 한다는 해결책은 제시하지 않음.

07

한 줄 정리

빠른 결과를 기대하지 말고, 성공에는 시간이 필요하므로 인내심을 길러야 한다.
